What the codes mean

Scenarios

T is a typical case, E an edge case, and F a failure case. T1 is a normal chat, T2 reviewing a transcript, E1 a long chat, E2 an emotional chat, F1 "you're an AI," and F2 things Harry can't know yet.

Spec lines

C is a canon fact, R a relationship, K a knowledge limit, and B a behavior rule. So K2 is knowledge-limit line 2.

Chats

The tool code, then the scenario. CLA is Claude, GPT is ChatGPT, and GEM is Gemini, so CLA-F2 is Claude running F2.
