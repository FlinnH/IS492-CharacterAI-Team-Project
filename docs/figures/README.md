# Figures

This folder holds the figures for the final report and the slides: charts, diagrams, and screenshots.

The CP4 package asks for scripts that reproduce the results, so each figure is listed here with the script that makes it and the data that script needs. The instructions call extra figures, like cost and latency charts, optional but nice to have.

Add a row when you add a figure. For a screenshot, write "screenshot" as the script, and say which screen and which chat it shows.
