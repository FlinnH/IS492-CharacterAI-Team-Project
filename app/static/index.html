What the codes mean

Scenarios

Spec lines

C is a canon fact, R a relationship, K a knowledge limit, and B a behavior rule. So K2 is knowledge-limit line 2.

Chats

The tool code, then the scenario. CLA is Claude, GPT is ChatGPT, and GEM is Gemini, so CLA-F2 is Claude running F2.
